## Thay đổi và kiểm tra tiếp theo theo thứ tự

1. **CD:** sửa Vercel CLI link cho artifact prebuilt, lấy project name từ đúng project ID và không kế thừa Root Directory `frontend`. GitHub CLI portable đã cài trong `.qa-data` (ignored), checksum kiểm tra; đang chờ chủ sở hữu hoàn tất OAuth. Cần cấu hình Environment staging variables và secrets `RENDER_API_KEY`, `VERCEL_TOKEN`, bypass nếu candidate Vercel được bảo vệ; không gửi giá trị qua chat. Chạy release từ CI đạt, kiểm artifact baseline/result rồi mới bật `CD_ENABLED`.
2. **Rollback cloud — Not Run:** chỉ diễn tập sau khi release GitHub có baseline hợp lệ và bản hiện hành khỏe; chạy rollback theo release run ID, kiểm SHA/health rồi deploy lại bản mong muốn. Chưa thay đổi traffic để giả lập sự cố.
3. **Restore cloud — Blocked:** chưa có kết nối operator được cấp quyền tới Atlas staging và đích backup/restore riêng. Staging đang dùng uploads ephemeral; ảnh tĩnh trên Vercel không chứng minh ảnh admin upload bền vững. Không đặt `RESTORE_PASSED`/`STORAGE_PASSED` bằng kết quả local.
4. **Monitor:** thêm workflow Staging health và probe chỉ đọc; chuẩn bị lịch 6 giờ nhưng chỉ bật bằng `STAGING_MONITOR_ENABLED` sau khi workflow và notification drill được xác minh. Alert delivery chưa được xác nhận.
5. **Bảo vệ phát hành:** cần GitHub quyền quản trị repository để bật PR review + required check `verify`, hạn chế branch deploy và xác minh bằng API. Chưa cấu hình reviewer production hoặc đóng production gates.
